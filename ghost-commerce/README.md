# Ghost Commerce

PotGrowHub commerce is designed as a no-inventory-first orchestration layer.

Supplier → Validation → Catalog ingestion → Normalization → PotGrowHub catalog → Cart → Checkout → Payment → Order → Fulfillment → Delivery → Tracking.

## Controls
- Supplier validation before publication
- Product normalization before listing
- Human/admin review gates
- No secrets in catalog data
- Payment provider abstraction
- Fulfillment and delivery provider abstraction
- Creator attribution and analytics hooks
